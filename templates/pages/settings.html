{{ icon('info', 18, 'notice__icon') }} How to connect an AI provider

No AI provider is connected out of the box, and DERB never pretends one is. The key is read on the server from the environment — it is never written into the database, the pages, the logs or a git commit.

Easiest and most private: run bash scripts/set_ai_key.sh from the project folder. It asks for the key with a hidden prompt (so it never reaches your shell history), saves it to .env.local with permissions 600, and refuses to write unless git ignores that file. On startup DERB prints only the names of the settings it loaded, never a value. A real environment variable still wins over the file, and only DERB_* keys are read.

Option 1 — Google Gemini (recommended on this device): one key from Google AI Studio, and the same call handles plain text-to-image and the customer’s own photos. 

# On this phone, before starting DERB MOBILE:
export DERB_AI_PROVIDER=gemini
export DERB_AI_API_KEY=your-gemini-api-key
# optional overrides:
export DERB_AI_IMAGE_MODEL=gemini-2.5-flash-image
export DERB_AI_TIMEOUT=90            # seconds
python app.py

Option 2 — any OpenAI Images API gateway (the default): 

export DERB_AI_PROVIDER=openai-images   # default, may be omitted
export DERB_AI_API_KEY=your-provider-api-key
export DERB_AI_BASE_URL=https://api.openai.com/v1
export DERB_AI_IMAGE_MODEL=gpt-image-1
export DERB_AI_QUALITY=high          # low | medium | high | auto
export DERB_AI_TIMEOUT=90            # seconds
python app.py

DERB_AI_PROVIDER chooses the client: gemini speaks the Gemini API directly (key in the x-goog-api-key header), while openai-images speaks the documented OpenAI Images API (/images/generations and /images/edits) so any OpenAI-compatible gateway works by changing DERB_AI_BASE_URL. Either way only the standard library is used — no SDK is installed. Turn the switch on above and use Check AI connection to prove the key works before generating a paid image.

Your text is never left to the image model. The AI only paints a background; every name, date, venue, phone number and logo is re-drawn by the built-in DERB layout engine, so nothing can be silently changed or dropped.
